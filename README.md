# Cube英文助手

以高中英文學科能力測驗為主要導向的英文學習APP，內含5個選擇大題及一個非選混合題，以大考中心提供單字庫為範本、歷屆學測出題方向為主，結合AI定時收集新聞主題以更新題目，題目解析包含逐格完整解析及文章中英翻譯。

另外包含字詞講堂功能，將基礎知識系統性拆分為:同義字、一字多義、字根、主題單字，及文法分類。硬核刷題之外也能補充常備知識。

鼓勵使用者提供出題意見，提供出題目標欄位以決定後續新題目主題以滿足多元需求並提升作答意願。

此repo只提供**安裝檔與版本說明**，不公開程式碼與技術細節。

## 下載與安裝

1. 到 [Releases](../../releases/latest) 下載最新的 `app-release-vX.Y.Z.apk`。
2. 用手機打開下載的檔案。第一次安裝時，Android 會要求允許「安裝不明來源的應用程式」，本APP不含任何病毒或勒索程式，此為系統限制，允許你用來下載的那個 App（例如瀏覽器）即可。
3. 之後有新版本時，APP 會自己跳出通知，按「前往下載」安裝新版即可，原本的紀錄都會保留。

目前只提供APK檔案，因此只有Android系統可以下載。

## 主要功能

- **題目查詢**：詞彙題、綜合測驗、文意選填、篇章結構、閱讀測驗、混合題型，可依大題、難度（Lv.1–6）、主題標籤篩選，也收錄歷屆學測試題。
- **詳細解析**：每個選項都有解析，文章可切換中文翻譯。
- **字詞講堂**：文法、同義字、一字多義、字根、主題單字的整理課程，附練習題。
- **錯題本**：依文法、單字、大題整理你還沒訂正的題目，也能在這裡看收藏。
- **Cube**：右上角的小方塊，會提醒更新、推薦講堂，也會跟你聊聊天。

## 意見回饋與問題回報

APP 內「設定與回報」頁有「BUG回報」與「出題目標」；意見表單可以從右上角的 Cube 打開。遇到問題、想看某個主題的題目，都可以直接在 APP 裡回報。

- 作答紀錄、回報與問卷內容只有開發者看得到，不會公開。
